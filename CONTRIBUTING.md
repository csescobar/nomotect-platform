# Contributing

## Before opening a pull request

- Keep the change focused.
- Add tests and documentation.
- Review security, privacy, i18n and accessibility impact.
- Add an ADR for significant architectural decisions.
- Avoid adding dependencies without documenting the reason and maintenance status.

## Commit style

Use clear imperative messages such as:

- `docs: define grid query architecture`
- `feat: add money grid type`
- `security: enforce tenant scope in grid queries`
