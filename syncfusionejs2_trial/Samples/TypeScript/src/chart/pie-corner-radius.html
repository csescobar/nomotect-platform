This sample demonstrates the company's budget distribution over a year using a donut chart with rounded corners.

In this example, you can see how to render and configure a donut chart with customized corner radii for each slice. The borderRadius property allows you to set the radius of the corners of the donut slices, enhancing the visual appeal of the chart. By specifying a value for borderRadius, you can create rounded corners for each slice, giving the chart a modern and polished look. The innerRadius property is used to create the donut effect by specifying the inner radius of the donut.

Tooltips are enabled in this example. To see the tooltip in action, hover over a slice or tap on it in touch-enabled devices.
