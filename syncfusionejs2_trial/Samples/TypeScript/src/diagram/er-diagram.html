This sample demonstrates a E-commerce Order Management ER diagram created using the Syncfusion® JavaScript Diagram. It visualizes how core entities such as users, orders, products, order items, addresses, and order history are structured and interconnected in a real-world database system.

This sample showcases how to create and interact with an ER diagram using the Syncfusion® JavaScript Diagram. The diagram is built using nodes of type 'Er' to represent database entities and their fields, while connectors define relationships with cardinality between entities.

Interactive features such as user handles allow adding or removing fields from entities. When selecting an entity node, a “+” user handle is displayed to add new fields, and the added fields can be interactively reordered using drag-and-drop actions. When selecting an individual field, a “-” user handle is shown to remove that specific field.

The diagram also includes built-in interactions such as selecting, zooming, panning, and editing elements, providing a flexible environment to explore and modify the ER model structure.
