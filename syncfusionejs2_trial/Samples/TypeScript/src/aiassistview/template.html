This sample demonstrates the template functionality of the AI AssistView control.

In this example, the AI AssistView control uses customizable templates for the banner, prompts, responses, suggestions, and footer. We have used the bannerViewTemplate, promptItemTemplate, responseItemTemplate and promptSuggestionItemTemplate to define the structure and appearance of these elements.

By using the executePrompt method you can trigger the prompt request externally and generates the output based on the promptRequest data returned. If found, the response will be displayed and suggestions are updated. If not, a message suggests connect to an AI service for real-time processing.
