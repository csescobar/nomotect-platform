This sample demonstrates the frozen rows and columns feature of the Grid. Scroll the movable content vertically or horizontally to see the frozen rows and columns remain in place while the rest of the content scrolls.

This feature allows users to freeze specific rows so they stay visible at the top during all data operations. This is achieved by setting the isRowFreeze callback. The callback is executed for each row before data is loaded into the grid and is re-evaluated whenever the data refreshes. It should return true to freeze the row and falsefalse for non-freezable rows.

In this demo sample, tickets rated as Dissatisfied or Very Dissatisfied are frozen at the top, the Ticket ID column is frozen on the left, and the Rating column is frozen on the right.

More information on frozen rows and columns can be found in this documentation section.
