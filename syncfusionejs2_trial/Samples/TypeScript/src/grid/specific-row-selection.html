This example showcases the Grid's row selection feature, enabling targeted row selection while using isRowSelectable to define which rows are selectable and which are not.

The isRowSelectable API in Syncfusion's EJ2 Grid allows control over row selection criteria through a simple callback that evaluates each row's data, returning **true** for selectable rows or **false** for non-selectable ones. This callback executes before the data is bound to the grid, ensuring proper setup during initial rendering.

For local data sources, the callback evaluates all records once on initial load, processing the entire dataset during binding, and re-evaluates only on full data refreshes. For remote data sources, fetched from a server, it evaluates only the current view's records on initial render and re-evaluates for each data action, such as paging, filtering, or sorting.

In this example, the isRowSelectable property is utilized to restrict selection for rows where the Status is **Cancelled**.
