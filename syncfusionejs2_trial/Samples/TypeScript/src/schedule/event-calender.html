Unplaned events

This demo showcases the setup and configuration of a calendar and schedule component. It illustrates how to integrate a calendar that updates the schedule's selected date and how to configure different views and settings for the schedule.

In this demo, we demonstrate the integration of a Syncfusion Calendar component with a Schedule component. The calendar allows users to navigate through dates, and the schedule dynamically updates to reflect the selected date.

The Schedule component is configured with multiple views, including Day, Week, Timeline Month, and Agenda. Each view is tailored with specific settings such as working hours and days. The calendar's change event updates the Schedule's selected date, ensuring synchronization between the two components.

The Schedule's time scale is set with a 60-minute interval and a slot count of 6, providing a detailed view of each hour. Sample event data is provided to illustrate how events are displayed within the Schedule component.

To integrate the Calendar and Schedule components, we inject the necessary modules and initialize each component with its respective settings. The calendar is rendered within an element with the ID "element", and the schedule is rendered within an element with the ID "Schedule".

This setup allows for an interactive and dynamic scheduling system, suitable for applications requiring detailed event management and date navigation.
