This demo demonstrates a data grid with predictive analytics and trend analysis. It utilizes Syncfusion EJ2 controls to display and manage data dynamically based on user selection.

To explore this and more Syncfusion EJ2 Smart AI integrations locally, check out our GitHub repository.

The page allows users to select a year from a dropdown, which triggers the calculation of trend analysis and predictive data. The grid updates to reflect trends with specific cell formatting and adds predictive data for the selected year. The spinner control provides a visual cue during data processing.
