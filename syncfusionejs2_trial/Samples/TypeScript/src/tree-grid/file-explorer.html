This sample showcases the TreeGrid component configured for an File Explorer use case.

The Tree Grid is used to represent the hierarchical data in a tabular format, combining the visual representation of Grid and TreeView controls.

In this demo, TreeGrid showcases a multi-level folder hierarchy similar to a file explorer, with a custom context menu that allows interactive right-click actions such as renaming files or folders, just like in a file manager.

More information on the TreeGrid can be found in this documentation section.
