### Frequently Asked Questions

This section addresses common questions about the **Block Editor** to help you troubleshoot issues and understand advanced features. Each question is organized into collapsible blocks for easy navigation.


* **How do I disable block drag-and-drop?**

    - To disable drag-and-drop functionality, set the configuration option `enableDragAndDrop` to `false`. This prevents users from rearranging blocks, which is useful for static layouts or controlled environments.

* **Can I add custom blocks?**

    - Yes, you can extend the editor by creating custom blocks. Use the `addBlock()` method to register new block types. This feature is ideal for adding specialized content like charts, tables, or templates.


* **Does the editor support inline formatting?**

    - Absolutely! You can apply **Bold**, *Italic*, <u>Underline</u>, ~~Strikethrough~~, and even <span style="color:red;">Color</span> and <span style=" background:rgb(128, 203, 196);">BackgroundColor</span> to text within blocks. Inline formatting enhances readability and allows you to highlight important details.


* **Is there an undo/redo feature?**

    - Yes, the editor supports **Undo** and **Redo** operations. This feature ensures that users can easily revert changes or restore previous states without losing progress.


These FAQs cover the most common queries, but if you need more assistance, refer to the official documentation or contact support. Keeping your editor updated and following best practices will minimize issues and improve performance.
