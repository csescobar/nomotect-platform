This sample demonstrates the infinite timeline scrolling feature in the Gantt Chart. Users can seamlessly scroll horizontally across an extended timeline without predefined start or end limits. This enables efficient planning and visualization of long-term schedules such as multi-year projects.

The Gantt Chart supports infinite timeline scrolling, allowing users to navigate across an extended date range without predefined limits. This is particularly useful for large-scale projects such as infrastructure planning, enterprise product roadmaps, and long-term resource management.

By enabling the enableInfiniteTimelineScroll property, the timeline dynamically expands as users scroll, ensuring a seamless and uninterrupted user experience.

Unlike traditional Gantt charts that rely on fixed date ranges or zooming techniques, this feature eliminates timeline constraints and provides a more intuitive navigation model.

Enables long-term planning across multiple years without manual timeline adjustments, while delivering a smooth and highly responsive scrolling experience.
