This Donut Chart example visualizes the global plug-in electric vehicle market share in 2023. The chart demonstrates the use of the borderRadius property, which allows customizing the corner radius of each slice in the donut.

In this example, you can see how to render and configure a donut chart with customized corner radii for each slice. The borderRadius property allows you to set the radius of the corners of the donut slices, enhancing the visual appeal of the chart. By specifying a value for borderRadius, you can create rounded corners for each slice, giving the chart a modern and polished look.

The innerRadius property is used to create the donut effect by specifying the inner radius of the donut.

Tooltips are enabled in this example. To see the tooltip in action, hover over or tap on a slice in touch-enabled devices.
