Essential JS 2 for JavaScript - Document Editor
The Document Editor component is used to create, edit, view, and print Word documents. This demo shows how to compare two Word documents and visualize their differences.
Original Document
Result Document (with tracked changes)

The Document Editor component supports comparing two documents with the help of Syncfusion DocIO and displays the differences between them.

In this example, you can:

  • Upload original and revised documents (.docx or .sfdt formats)
  • Compare the documents to see the differences
  • View the differences with or without tracked changes
  • Download the compared result document

More information about the document editor features can be found in this documentation section.
