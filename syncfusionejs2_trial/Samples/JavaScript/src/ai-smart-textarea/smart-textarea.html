This example demonstrates how to use the Smart Text Area component, including its key properties and functionalities. The component supports various features such as inline suggestions and real-time input handling.

The SmartTextArea component is configured with the following properties:

  • UserRole: Sets the role of the current user, which may influence suggestions or access controls.
  • UserPhrases: Provides predefined phrases or suggestions relevant to the user’s role, enhancing the context of the input.
  • Width: Defines the width of the text area. In this example, it is set to 75% of its container’s width.
  • Placeholder: Displays a hint or instruction within the text area when it is empty. Here, it prompts the user with Enter your queries here.
  • RowCount: Specifies the number of visible rows in the text area, set to 5 in this example, to accommodate more text.
  • FloatLabelType: Controls the label behavior. The FloatLabelType.Auto option ensures that the label floats above the text area when it is focused or contains text.

This setup facilitates a flexible and interactive text area, ideal for capturing and processing user input efficiently.
