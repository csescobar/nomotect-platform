Pinned Rows

This sample demonstrates that important rows can be pinned at the top and important columns frozen on the left or right, keeping them visible at all times. Scroll vertically or horizontally to see how these pinned rows and frozen columns remain fixed while the rest of the grid moves beneath or beside them.

Description

In this demo, tickets rated Dissatisfied or Very Dissatisfied are automatically pinned to the top through the isRowPinned callback function. The grid applies column freezing by locking the Ticket ID column on the left and the Rating column on the right using the column.freeze property. The feature supports dynamic row pinning so that any row can be pinned or unpinned through the context menu, and this functionality is configured by defining the contextMenuItems property with the PinRow and UnpinRow options.
