Licensing

Starting with v16.2.0.x, projects that reference Syncfusion® evaluation builds or npm packages require a license key. This key is different from the setup unlock key and must be generated from your Syncfusion® account.

  • Generate your license key from your Syncfusion® account.
  • Add the key to projects that reference Syncfusion® npm packages.
  • See the licensing guide for detailed steps.

For licensing questions, contact licensing@syncfusion.com.
