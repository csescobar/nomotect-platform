# ADR 0004 — License the Community Platform under Apache 2.0

## Status

Accepted

## Context

The project requires genuine open-source adoption, enterprise legal clarity and a separate path for future commercial capabilities.

## Decision

License the community repository under Apache License 2.0. Maintain any future commercial enterprise repository under separate proprietary terms.

## Consequences

Commercial use, modification and redistribution of the community platform are permitted under Apache 2.0 conditions. Contributors and users receive an explicit patent grant. The community core must remain useful for serious applications and must not be intentionally crippled to force commercial adoption.
